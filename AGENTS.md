# Design Context

This project has a documented design system:

- **`PRODUCT.md`** — strategic: register (brand), users, purpose, brand personality, anti-references, design principles, accessibility targets (WCAG AA)
- **`DESIGN.md`** — visual: colors (OKLCH), typography (Geist), elevation (flat-by-default, tonal layering), component specs, do's and don'ts
- **`.impeccable/design.json`** — machine-readable sidecar with component CSS snippets for the live panel

Key constraints: dark-first (`#050505`), indigo accent only, no gradient text, no box-shadows, no dev portfolio clichés, no uppercase eyebrow above every section.
